# HMI Prototype

Robotaxi **Unexpected Failure Passenger Support HMI** static prototype: cover page plus cabin (`demo_carin`) and mobile (`demo_mobile`) showcases.

## GitHub Pages

1. Repository **Settings → Pages**
2. **Build and deployment**: Source **Deploy from a branch**
3. Branch **main** (or `master`), folder **`/` (root)**
4. Save. The site updates in about one minute.

### Live URL

With this repository name, GitHub serves a **project site** at:

**https://nothingmay.github.io/hmi_prototype.github.io/**

Open the link above (replace with your account name if you forked). Entry point: **`index.html`** (default when opening the site root).

### Files

| File | Role |
|------|------|
| `index.html` | Cover / navigation |
| `demo_carin.html` | Vehicle (cabin) demo shell |
| `demo_mobile.html` | Mobile demo |
| `cabin_ui.html` | Cabin UI (embedded in demo) |
| `mobile_ui.html` | Optional standalone mobile UI |

All asset paths are **relative**; keep these files in the repository root for Pages.
